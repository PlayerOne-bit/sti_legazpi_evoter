How to install
  1. Tap Download APK and open the file when it finishes.
  2. If Android asks, allow your browser or Files app to install unknown apps.
  3. Tap Install, then open STI eVoter.

Windows

Windows 10 and 11, 64-bit

Recommended for you
Download for Windows
How to install
  1. Download the .zip and Extract all to a folder, for example Documents\STI eVoter.
  2. Open sti_legazpi_evoter.exe.
  3. If Windows SmartScreen appears, choose More info > Run anyway.
